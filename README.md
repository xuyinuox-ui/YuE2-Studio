## 1. Product Overview

YuE2 Studio is a locally running macOS AI music workstation that provides:

- Audio to ABC: Uses SheetSage2 and MERT to extract tempo, key, structure, vocal, and instrumental melody;
- Music generation: Uses YuE2-3B and YuE2-Vae, by default running via MLX on Apple Silicon;
- One-click installation: Automatically installs an independent Python environment, dependencies, and full models on first launch;
- Domestic mirrors and resumable downloads: Automatic speed testing, segmented downloads, and retention of unfinished shards;
- Self-check repair: Checks models by final files and exact sizes, and supplements only what is missing;
- Task control: Both transcription and generation can be interrupted;
- Local history, logs, playback, and clean uninstall.

## 3. Installation and First Launch

1. Place `YuE2 Studio.app` in the Applications folder.
2. Double-click to launch. On first launch, it checks the environment and lists the items to be installed.
3. After clicking Install, keep the network and power stable. If a download is interrupted, completed segments will not be lost, and the next launch will resume.
4. The installer verifies the final weights of YuE2-3B, YuE2-Vae, SheetSage2, and MERT; merely having directories or residual shards will not be judged as complete.
5. Once "Complete" appears and "worker ready" is displayed, it is ready for use.

Runtime data is dynamically saved for the current macOS user to:

```text
~/Library/Application Support/YuE2Studio/
```

Works are saved by default to:

```text
~/Music/YuE2Studio/
```

Paths do not hard-code the developer's name; when moved to another Mac, they automatically use that account's user directory.

## 4. Basic Usage

### 4.1 Extracting ABC from Audio

1. Drag audio into the Source area or click "Choose File."
2. Select "Lead Vocal + Instrumental Main Melody," "Lead Vocal Melody Only," or "Melody + Chords."
3. Click "Transcribe to ABC." The interface displays cumulative elapsed time and, upon completion, displays speed relative to real time.
4. The transcription result is automatically filled into the ABC area; it can be copied, edited, and used for subsequent generation.
5. Clicking Stop can interrupt transcription; the background process will be terminated and MPS memory released.

### 4.2 Generating Music

1. Enter a style prompt and lyrics.
2. Select Planning, quality, number of songs, maximum length, and random seed as needed.
3. MLX is selected by default; PyTorch (MPS) serves only as a compatibility path, and Neural Engine is suitable for specific lengths.
4. If a reference melody is needed, use the ABC generated by transcription.
5. Click Generate. Clicking Stop can cancel queued or currently executing generation tasks.

Tip: Full quality is usually significantly slower than draft; the first generation also includes model loading time.

## 5. Download, Self-Check, and Repair Mechanisms

- Prioritize testing available domestic PyPI, Python, and model mirrors, and select sources according to speed test results;
- Large models use multi-connection, segmented, resumable downloads; temporary shards are not treated as complete weights;
- YuE2-3B and YuE2-Vae are verified separately by final file and exact byte count;
- When the main model is complete but VAE is missing, only VAE is resumed; the main model is not downloaded again;
- The installer rewrites the engine configuration corresponding to the current user and current app location on every launch;
- Installed weights are passed to the generation engine through local absolute paths and do not rely on online resolution of Hugging Face revision;
- The app does not carry the development machine's username, project path, or `engines.json`.

Mirrors are external services; speed and availability cannot be permanently guaranteed. When all mirrors are unavailable, the installer may fall back to upstream sources; users should comply with the terms of the mirrors used and upstream services.

## 6. Frequently Asked Questions

### Installation reports incomplete models

This is the self-check preventing incomplete weights from entering the generation process. Keep the app open and continue installation; existing shards will be reused.

### Generation reports missing `model.safetensors`

This indicates the corresponding weights have not yet been fully merged. Version 1.2.4 will no longer judge this state as installation complete; restart the app and complete the supplementation.

### Input fields cannot paste

Since 1.2.1, a standard macOS Edit menu has been provided, supporting ⌘V, ⌘C, ⌘X, ⌘A, ⌘Z, and ⇧⌘Z.

### Window is difficult to drag

Since 1.2.2, the top frosted area is a native drag region and avoids the red, yellow, and green buttons.

### How to completely uninstall

Select "Clean Uninstall…" from the app menu. The app, local Python environment, models, cache, uploads, and logs will be moved to the Trash; works already generated to the music directory will not be deleted.

## 7. Privacy and Network Statement

- Audio, lyrics, ABC, and generated results are processed on the local machine; the interface only connects to the `127.0.0.1` local service;
- No accounts, advertising, analytics, or telemetry are integrated; the runtime environment explicitly disables Hugging Face telemetry;
- First installation and repairs connect to the network to probe mirrors and download Python, dependencies, models, and necessary files; external download services will see network requests and IP addresses;
- Imported audio is copied to the local app data directory, and logs are also stored locally;
- Users should only process audio, lyrics, melodies, and other materials that they own the rights to or are authorized to use.
